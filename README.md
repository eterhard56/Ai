# РАЗ!Колбас — сайт для заказов

Лендинг + каталог с корзиной. Заказ уходит в **Max** готовым текстом или по телефону Андрею.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Что подставить перед показом клиенту

В `src/data/products.ts` → `shop.maxChatUrl` — прямая ссылка на чат Max (из профиля: QR → Поделиться).

Телефон уже указан: `+7 (912) 846-22-44`.

## Как продавать сайт владельцу

Сейчас клиенты листают фото во вложениях Max-чата. Сайт даёт:

1. **Каталог с ценами** — как витрина, без поиска по фото.
2. **Корзина → Max** — клиент нажимает «Отправить», Андрей получает готовый заказ.
3. **Работает без Max** — можно зайти с браузера и позвонить.
4. **Под заказ** — отдельный блок (пельмени, нарезка, заливное).
5. **Без предоплаты** — как они привыкли, сохраняем доверие.

Речь на 30 секунд:

> «Сейчас заказ — это переписка и фото. Сайт — ваша витрина в интернете: человек видит цены, кладёт в корзину и присылает вам готовый заказ в Max. Вы подтверждаете и везёте — как сейчас, только без путаницы.»
