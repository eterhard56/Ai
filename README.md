# РАЗ!Колбас — витрина как каталог

Каталог в стиле карточек маркетплейса (Ozon / Wildberries): фото, цена, название, описание, «В корзину».

## Для покупателя
1. Смотрит витрину / фильтр категорий
2. Открывает карточку — полное описание
3. Кладёт в корзину
4. Оформляет заказ → **список товаров уходит в Max** админу

## Для админа (добавление товаров)
Откройте `#admin` или кнопку «Управление каталогом» внизу сайта.  
Пароль по умолчанию: `razkolbas` (меняется в `src/data/products.ts` → `shop.adminPassword`).

Товары сохраняются в браузере (localStorage). Можно добавить / редактировать / скрыть / удалить.

## Запуск
```bash
npm install
npm run dev
```

## Max
Кнопка «Отправить список в Max» открывает шеринг с готовым нумерованным списком заказа для Андрея.
