# РАЗ!Колбас — витрина для продажи

Готовый сайт под показ Андрею: бренд-герой, каталог как маркетплейс, заказ списком в Max, админка «пришла партия» вместо 1С.

## Запуск
```bash
npm install
npm run dev
```

## Демо
- Витрина: `/`
- Админка: `#admin` · пароль `razkolbas`
- Сценарий продажи: `SALES_PITCH.md`

## Что умеет
- Карточки товаров (цена, скидка, ★, описание)
- Корзина + тост → нумерованный заказ в Max
- Админка: быстрая цена, Есть/Мало/Нет, «Партия приехала»
- Питч на сайте для показа за 1 минуту
