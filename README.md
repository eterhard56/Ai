# РАЗ!Колбас — витрина для продажи

Готовый сайт под показ Андрею: каталог как WB/Ozon, заказ списком в Max, админка «пришла партия» вместо 1С.

## Запуск
```bash
npm install
npm run dev
```

## Демо
- Витрина: `/`
- Админка: `#admin` · пароль `razkolbas`
- Сценарий продажи: `SALES_PITCH.md`

## Что умеет
- Карточки товаров (цена, скидка, ★, описание)
- Корзина → нумерованный заказ в Max
- Админка: быстрая цена, Есть/Мало/Нет, добавление товара
